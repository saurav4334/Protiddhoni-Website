broadcast-eid-sale.js
Node.js
// Eid sale broadcast — 2.8L customers, all carriers
import Protiddhoni from '@protiddhoni/node';

const vr = new Protiddhoni(process.env.VR_KEY);

const job = await vr.broadcast.create({
  name: 'Eid Sale 2026',
  audience: 'segment_dhaka_active_buyers',
  script: {
    language: 'bn-BD',
    voice: 'tahmina-female',
    text: 'Assalamu alaikum {{name}}! Eid offer — {{discount}}% off. Press 1 to order.',
    dtmf: { "1": 'sms_offer_link' }
  },
  schedule: {
    start: '2026-04-26T11:00:00+06:00',
    pacing: 1200      // calls/sec
  },
  retry: { attempts: 2, delayMin: 30 }
});

// → bc_8h2k4f9... · queued · 2,84,621 calls
console.log(job.id, job.status);

FAQ

Common questions about voice broadcast

How fast can I send to lakhs of numbers? +
Peak throughput is 14,000 calls per minute across all four BD carriers, so 2.8 lakh numbers complete in roughly 20 minutes. You can lower the pacing if you want to spread the load over the day.
Do I need to negotiate with carriers myself? +
No. We have direct interconnects with Grameenphone, Robi, Banglalink, and Airtel. You get one contract with us and we handle the carrier relationships, throughput negotiations, and sender ID approvals.
What languages and voices are supported? +
12 native Bangla voices (male/female, formal/conversational), plus English (US/IN), Hindi, and code-mixed Banglish with correct phonetics. You can also upload pre-recorded MP3/WAV if you prefer a human voice — say, your CEO or a brand spokesperson.
How does opt-out / DNC work? +
Press 9 during any promotional call and the number is suppressed across your entire account within seconds. We also auto-sync with the BTRC DNC list daily and reject numbers on it before placing calls.
Can I personalize each call? +
Yes — every script supports placeholders like {{name}}, {{amount}}, etc. Pass them in the audience CSV or via the API. The TTS engine handles Bangla pronunciation correctly even for English brand names and numbers.
What does it cost per call? +
Voice broadcast starts at ৳0.85 per connected call on Business plan, ৳0.65 on Enterprise. Failed calls (busy, switched off) are not billed. See pricing for the full breakdown.
Can I record DTMF responses for follow-up? +
Absolutely. DTMF presses are captured per call, fired via webhook in real time, and shown on the dashboard. You can branch — "Press 1 to receive an SMS link, Press 2 for a callback" — and we'll handle the routing automatically.
Is broadcast available in all 64 districts? +
Yes. We deliver to all 64 districts and 487 upazilas — anywhere a Grameenphone, Robi, Banglalink, or Airtel signal reaches. Rural pickup rates are typically 8–12pp higher than urban because voice is still the dominant communication channel outside the metros.
