Protiddhoni — static site

Upload the CONTENTS of this folder into public_html/.
No PHP, database, or Laravel required.

Contact form: uses FormSubmit (https://formsubmit.co/hello@protiddhoni-bd.com).
First submission triggers a one-time email to confirm the address.
Change the address by editing the <form action> in contact.html.

Add a 1200x630 PNG at assets/images/og-cover.png for social link previews.
